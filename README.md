# Technical Study Notes

A personal learning repository containing structured notes, study guides, and reference material for key technical domains including cloud computing, programming, databases, and API-related topics.

This repo is designed as a quick-reference study space for understanding core concepts, practicing fundamentals, and revisiting important topics while preparing for interviews or self-paced learning.

## Contents

- [AWS-Cloud-Practitioner.md](./AWS-Cloud-Practitioner.md) — AWS Cloud Practitioner study guide covering AWS services, architecture basics, security, pricing, and exam preparation.
- [Java-Notes.md](./Java-Notes.md) — Java fundamentals, OOP, collections, concurrency, JVM concepts, and modern Java features.
- [Python-Notes.md](./Python-Notes.md) — Python basics, data structures, functions, OOP, file handling, and best practices.
- [SQL-Notes.md](./SQL-Notes.md) — SQL concepts from beginner to advanced, including joins, normalization, transactions, indexing, and interview-focused practice.
- [Lablabee](./Lablabee) — Additional study notes and reference material related to API usage and practical learning.

## Focus Areas

- Cloud Computing (AWS)
- Java Development
- Python Programming
- SQL and Database Concepts
- API/Integration Learning
- Technical Interview Preparation

## How to Use This Repository

1. Open the topic-specific notes file that matches your current learning goal.
2. Read the concepts in order and try the examples or practice questions.
3. Use the notes as a revision guide before interviews or project work.
4. Supplement them with official documentation and hands-on practice.
